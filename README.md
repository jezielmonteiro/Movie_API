# 🎬 Sistema de Cadastro de Filmes

## 📚 Atividade Extra

Projeto desenvolvido em **Java** utilizando o **Spring Boot**, com o objetivo de criar um pequeno sistema para cadastro de filmes.

## 💻 Tecnologias utilizadas

- Java
- Spring Boot
- IntelliJ IDEA
- Maven

## 🎥 Classe Filme

O projeto possui uma classe chamada `Filme`, contendo as seguintes informações:

- **ID** – Identificador do filme
- **Title** – Nome do filme
- **Genre** – Gênero do filme
- **releaseYear** – Ano em que o filme foi lançado
